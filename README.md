# 식품 쇼츠 소재 검증 자동화

GitHub 저장소에 소재(제품명+메모)를 적어두면, Claude Code의 `/validate` 루틴이
정해진 단계대로 소재를 검증하고 대본 방향까지 제안해 주는 작업 공간입니다.

## 처음 한 번만 할 일

1. 이 폴더 전체를 GitHub 저장소로 올립니다.
2. `CLAUDE.md` 의 "채널 정보" 빈칸을 채웁니다.
3. `prompts/1_소재검증_프롬프트.md` 와 `prompts/2_대본방향_프롬프트.md` 의
   `[여기에 작성]` 빈칸을 본인 채널 기준으로 채웁니다.  ← **이걸 채워야 루틴이 동작합니다.**

## 매번 쓰는 법

1. `소재메모.md` "검증 대기"에 소재를 추가:
   `- [ ] 제품명 — 메모`  (여러 개 한꺼번에 쌓아둬도 됩니다)
2. 저장소 폴더에서 Claude Code 실행 후 `/validate`
   - 대기 중인 소재를 **위에서부터 최대 10건** 가져와
   - 각각 **웹검색으로 사실 확인 → 적합성 검증 → 대본 초안 작성**
3. 결과:
   - `평가결과.md` → 검증 결과가 **맨 아래에 계속 누적**(덮어쓰지 않음)
   - `소재메모.md` → 검증한 항목마다 `✅ 날짜 · 판정` 표시
   - 변경사항은 자동으로 **main 브랜치에 커밋·푸시**됩니다

> ⚠️ 자동 푸시 주의: 루틴이 끝나면 `평가결과.md`·`소재메모.md` 변경을 main에 바로 push 합니다.
> 저장소가 `git clone`된 상태이고 `origin`/push 권한이 설정돼 있어야 합니다.
> 검토 후 수동 푸시를 원하면 `validate.md`의 7단계를 지우면 됩니다.

## 폴더 구조

```
food-shorts-validator/
├── .claude/commands/validate.md   ← 검증 루틴 (수정 X)
├── CLAUDE.md                      ← 채널 정보 (채우기)
├── prompts/
│   ├── 1_소재검증_프롬프트.md       ← 적합성 기준 (채우기)
│   └── 2_대본방향_프롬프트.md       ← 대본 방향 기준 (채우기)
├── 소재메모.md                    ← 입력
├── 평가결과.md                    ← 출력 (자동 덮어쓰기)
└── README.md
```

> 참고: Claude Code 커스텀 슬래시 커맨드는 `.claude/commands/`의 마크다운 파일명이
> 곧 명령어가 됩니다. (`validate.md` → `/validate`)
